# Хотелки

Общий список на двоих: вишлист и подарки, ссылки, куда сходить и съездить, кино, книги, идеи — чтобы ничего не забыть. Быстро скинул сверху или снизу пару слов / ссылку — сохранилось у обоих.

Статический PWA без своего бэкенда. `index.html` + `app.js`. Данные — локально (localStorage), а между телефонами синхронизируются через один общий **GitHub Gist**.

## Как устроено
- **Быстрый ввод внизу.** Пишешь «хочу…» или вставляешь ссылку → Enter/↑. Ссылка распознаётся сама, показывается доменом-чипом (тап открывает). Попадает в текущую тему (в режиме «Всё» — в «Идеи и разное»).
- **Темы (чипы сверху).** Уже заведены: 🎁 Вишлист/подарки, ✈️ Поехать, 📍 Сходить, 🍽️ Кафе и рестораны, 🎬 Кино и сериалы, 📚 Книги, 🔗 Ссылки, 💡 Идеи и разное. Свою тему — «＋ Тема». «Всё» — единая лента по разделам.
- **Кто добавил.** У каждой записи цветной кружок с инициалом (Антон / Диана) — видно, чья хотелка.
- **Отметить сделанным.** Кружок слева — «купили / сходили / посмотрели». Уходит в раздел «Сделано».
- **Детали.** Тап по записи — заметка, цена, ссылка, перенос в другую тему, удаление. Кнопка ☰ слева от поля — добавить сразу с деталями.
- Светлая/тёмная тема, ставится на домашний экран, **работает офлайн**.

## Синхронизация на двоих
Хранилище — один секретный Gist. Оба телефона используют **один и тот же** GitHub-токен (доступ только к `gist`), тогда список общий.

1. Настройки (⚙️) → «Как получить токен» → на github.com создать **classic**-токен с галочкой **gist**, без срока (`No expiration`).
2. Вставить токен → «Подключить». На первом устройстве гист создаётся автоматически.
3. На втором телефоне — те же Настройки, вставить **тот же токен**. Приложение само найдёт общий гист по метке и подтянет список.

Слияние — по каждому пункту отдельно (побеждает более свежее изменение), удаления помечаются «надгробием» и подчищаются через 60 дней. Изменения уходят через ~1.5 с после правки, а также при открытии приложения и возврате сети. Токен хранится только на устройстве, в открытый доступ ничего не публикуется (gist секретный).

## Push-уведомления «когда второй добавил»
Приходит push, когда партнёр добавляет новую хотелку (тебе — о её записях, ей — о твоих; автору о своих не приходит). Своего сервера нет: раз в ~10 минут воркер **GitHub Actions** (`.github/workflows/notify.yml` + `notify/notify.mjs`, библиотека `web-push`) читает гист, находит новые записи и рассылает push подпискам из файла `hotelki-push.json`.

Настроено в репозитории: секрет `VAPID_PRIVATE`, переменные `VAPID_PUBLIC` / `VAPID_SUBJECT`, публичный VAPID-ключ зашит в `app.js`.

**Что осталось сделать один раз:**
1. Добавить секрет **`GIST_TOKEN`** в репозиторий (Settings → Secrets and variables → Actions → New repository secret) — значение = тот же GitHub-токен со scope `gist`, что вводишь в приложении. Он нужен воркеру, чтобы читать гист.
2. На **каждом** телефоне: установить приложение на экран «Домой» (iOS 16.4+), открыть, ⚙️ Настройки → **«Включить уведомления»**, разрешить.

Оговорки iOS: push для PWA работает только с домашнего экрана (не во вкладке Safari) и iOS 16.4+. Задержка — минуты (это опрос по расписанию, не мгновенно). Мёртвые подписки (410) воркер выкидывает сам.

## Локальный запуск
```bash
python3 -m http.server 8000 --directory .
```

## Деплой
GitHub Pages из ветки `main`, корень репозитория (как «На полях»). После установки на iPhone: Поделиться → «На экран Домой».

## Файлы
- `index.html` — оболочка и стили
- `app.js` — вся логика и синхронизация с Gist
- `sw.js` — service worker (кэш оболочки, офлайн)
- `manifest.webmanifest` — манифест PWA
- `make_icons.py` — генератор иконок
